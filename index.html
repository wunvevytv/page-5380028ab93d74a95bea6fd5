客户端下载与操作说明

云图小镇不把配置写死在安装包内。正确顺序是：官网选择套餐并开通 → 复制订阅地址 → 下载对应客户端 → 导入订阅 → 测延迟后连接。以下为官方下载对照，链接指向本页说明锚点，实际安装包请在登录后的下载区获取，避免第三方修改版。

多端客户端

  • Windows 桌面端：适合规则分流与系统代理
  • macOS 桌面端：可与系统网络偏好配合
  • Android 客户端：支持订阅更新与分应用代理
  • iOS 客户端：常用 Shadowrocket、Surge、Stash 等导入订阅
  • Clash Meta / Mihomo：适合需要自定义规则的用户
  • Linux 命令行或图形前端：导入相同订阅即可

操作步骤

  1. 打开云图小镇官网，对照套餐流量、设备数与线路类型下单。
  2. 在用户中心复制订阅链接，不要把链接发到公开群组。
  3. 按系统下载官方客户端或兼容的订阅客户端。
  4. 选择「从 URL 更新」或「导入订阅」，粘贴链接并更新节点列表。
  5. 先用延迟测试筛选节点，再按规则模式连接；游戏场景可在旗舰版中优先 IPLC 相关分组。
  6. 若无法访问，检查系统时间、订阅是否过期、设备数是否超限，再提交工单。

官方下载只通过已登录的控制台发放。本页不托管安装包，也不使用外部资源，以减少被调包风险。

节点与加速能力

云图小镇将线路分为普通节点池、全节点原生解锁与 VIP 高带宽三类，分别对应基础版、旗舰版与团队版。区域覆盖常见的香港、日本、新加坡、美国西岸与欧洲入口，具体可用列表以订阅更新结果为准。

如何理解分层

  • 普通线路：满足网页、邮箱与基础流媒体，晚高峰可能需要手动换节点。
  • 原生解锁：旗舰版强调同一套餐内全节点对常见流媒体的解锁策略，减少「只有个别节点能播」的情况。
  • IPLC 游戏优化：面向对抖动敏感的对局与更新，不替代本地运营商质量，但可减少绕路跳数。
  • VIP 高带宽：团队版出口更适合多人同时拉取大文件或会议上行。

网络加速不是无限带宽承诺。请按月度流量规划 4K 播放、游戏更新与网盘同步；需要更高并发时直接对照团队版设备数与定制路由说明。

常见问题

云图小镇提供的是机场订阅还是单独的 VPN 客户端？

两者是一套流程里的不同层。云图小镇先通过机场订阅下发节点与流量配额，再用 Windows、macOS、Android、iOS 或 Clash 系客户端完成连接。官网下载的是客户端与导入说明，真正的线路列表在订阅更新之后出现。

如何从官网完成客户端下载并导入订阅？

登录后进入下载区选择系统，安装完成后在客户端内粘贴用户中心的订阅 URL，执行更新。iOS 用户通常把订阅导入 Shadowrocket 或 Surge；桌面用户可使用官方包或 Clash Meta。不要使用来路不明的「一键包」，以免订阅被二次转发。

基础版、旗舰版和团队版该怎么选？

偶尔使用、三台设备以内、能接受基础流媒体，选基础版。需要每月约 300GB、五台设备、原生解锁和 IPLC 游戏优化，选旗舰版。二十台设备、千 GB 流量、要专属带宽或定制路由，选团队版。年付按页面标示为十个月口径，适合已经确认长期使用的账号。

流量用尽或设备超限会发生什么？

流量用尽后新连接会被限制，可等待下个计费周期或在官网升级套餐。设备数按同时在线会话统计，超出后新设备无法握手，需要在客户端断开闲置会话。团队版把上限放到 20 台，仍建议为服务器和手机分开配置，避免重复登录占满名额。

旗舰版的 IPLC 与优先工单怎么用？

IPLC 分组出现在旗舰订阅的节点列表中，适合对延迟和抖动更敏感的游戏与实时通话。7x24 优先工单用于线路异常、解锁失效或订阅无法更新等故障，提交时请附上客户端名称、系统版本与错误截图文字描述，便于值班人员对照节点状态。

为什么强调走云图小镇官网而不是第三方镜像？

机场订阅一旦泄露，他人可以耗尽你的流量或把节点用于违规用途。官方网站只在登录态显示订阅与客户端校验信息。本页提供套餐对比、操作说明与问答，不收集表单，下载跳转也保持在页面锚点，方便你核对是不是同一品牌入口。
